# Automatización de redes

Proyecto académico que consulta una API REST mediante HTTPS, procesa la respuesta JSON y exporta los registros a archivos JSON y CSV.

> La API JSONPlaceholder se usa con fines de demostración. Sus datos son ficticios y no representan dispositivos reales.

## Requisitos

- Python 3
- pip
- Conexión a Internet

## Instalación

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
